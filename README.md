# MadewithLove Automation

A private, single-owner tool for creating original procedural animation Shorts
for [MadewithLove](https://www.youtube.com/@madewithlove302).

The owner authorizes Google access, selects the MadewithLove channel, and
configures the private GitHub runner. The worker renders its own animations,
uploads videos through YouTube API Services, and uses the reported engaged-view
counts of past videos to choose future variants. It does not offer public
accounts or process other creators' channels. It does not calculate a combined
performance score. No YouTube player is embedded in this documentation.

Public publishing is disabled during setup and API audit preparation.
